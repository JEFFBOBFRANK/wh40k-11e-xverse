# EC rules presentation

Catalogue revision 23. Main reference contains Combat Drugs, Bound Excess and Sublime Strategist only. Combat Drugs contains dosages, Pain Brings Clarity, Stupefied/recovery and all eight Warband Elixirs. Removed general core rules, mustering guides, recipient lists and repeated model exceptions. Named Signature Elixir abilities contain activation timing, duration, effects and use limits. Model exceptions remain on their datasheets.

Space Marines comparison: detachments use individually named Rules objects (e.g. Codex Discipline), fixed Disposition category links, and their existing Detachment Points cost. EC now follows that structure instead of a generic Detachment rule containing a source-page dump. Stratagems retain their separate conditional reference selection. Allied rituals appear with the detachments that grant them; Manifestation remains on the allied datasheets.
